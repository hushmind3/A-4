# Consumer mobile surface

The user-facing app is a life assistant messenger, not an engine administration console.
Keep existing persona, Korean workflows, device permissions, contacts, schedules, memory,
documents, task results and approval screens. Account/settings expose Google login,
quota, and one model selection. No server host, port, tunnel, tool registration, or
skill installation in the regular navigation. The old engine-settings route resolves
to account settings to handle saved navigation safely. Retain PC-specific source
for developer work; it is not the normal consumer workflow. No PC backend changes.
Unsupported PC-dependent voice/media functions are not offered as working independent
features; use Android speech input until independent realtime media is implemented.
Existing model-only mobile runtime is not a claim that all device workflows are connected.
