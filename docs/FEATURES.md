# 기능별 구현 상태

기준 자료: `pickle-client-1.1.20.apk`의 `assets/pickle/svg` 779개 아이콘, `assets/ui/vocabulary.json`(74개 UI atom, 79개 화면 액션, 160개 시스템 액션), `assets/ui/public.ndjson`의 디자인 토큰과 온보딩/법무 화면, `AndroidManifest.xml`의 권한·서비스·딥링크·위젯.

표기:
- **구현**: 화면과 상호작용이 데모 데이터로 동작
- **UI만**: 화면은 있으나 실제 외부 서비스/권한 연결 필요
- **미구현**: 원본 기능이지만 이 소스에 없음

## 알려진 차이

1. **메인 화면의 정확한 픽셀 배치**: 원본은 서버가 내려주는 UI 번들로 화면을 그립니다. APK에는 온보딩·법무 화면만 포함되어 있어, 채팅/탐색/친구/프로필은 디자인 토큰과 기능 목록을 근거로 재구성했습니다.
2. **브랜드/아트**: 원본 로고·캐릭터 이미지·일러스트를 복제하지 않았습니다. 색상 토큰과 도형 캐릭터로 대체했습니다.
3. **서버 의존 기능**: 결제, OAuth, 푸시, LiveKit, 지도, 연락처 매칭은 실제 키와 서버가 있어야 완성됩니다. UI와 연결 지점은 준비되어 있습니다.
4. **일본어**: 원본은 `ko`/`en`/`ja`를 지원하지만 이 소스는 `ko`/`en`만 제공합니다.

이 목록은 “100% 재현”을 주장하기 위한 것이 아니라, 무엇이 실제로 동작하고 무엇이 백엔드/키를 기다리는지 명확히 하기 위한 기록입니다.
